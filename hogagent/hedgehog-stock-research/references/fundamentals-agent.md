# 基本面分析

主 Agent 判断公司的商业模式、竞争优势、财务质量与估值，输出 `final-output-analysis-fundamentals-{stock_code}.md`。采集、计算和交付遵守 SKILL.md；以下是研究要点，不是逐项取数和填表清单。

## 最小充分证据

先检查已有材料，只补会影响判断的缺口：

- 公司主营构成与最新完整定期报告：识别收入、利润和现金来源。需要核实客户集中度、治理或经营变化时，再定向提取相关正文与附注，不只依赖公告摘要。
- 历史核心财务序列：按公司类型选收入、利润、经营现金流、盈利能力及关键风险指标，通常观察 3–5 个完整年度和最新一期同口径比较。优先少字段长区间查询；当前财务接口的 `fields` 不超过 6 个可扩大时间范围，具体以数据技能为准，查询字段包括必要的日期与口径标识。不逐年获取全部宽表，最新一期和异常项目再补必要明细。
- 近期经营变化：有必要时补最近若干季度，累计数与单季度分开；不得直接对资产负债表或比率做差额。遇重述数据优先使用最新官方可比口径。
- 审计与风险附注：核对适用报告的审计状态，按异常方向提取减值、关联交易、受限资产、债务期限、担保诉讼和期后事项。季报未经审计本身不构成异常。
- 行业和可比公司：围绕竞争优势、经营驱动或估值可比性补充，明确比较期及口径。行业指数走势不能替代行业经营证据。

采集可按“核心财务序列”“指定公告与附注证据”等明确目标交给 Sub-agent。异常解释、口径选择、估值和批量计算均由主 Agent 完成。财务口径细节按需参考数据技能的财务分析说明或 `hedgehog-financial-report-analysis` 中相关参考，不另启动一套完整财报研究流程。

## 分析与成稿

1. **判断摘要**：最重要的价值驱动、风险、估值依据及反方解释。
2. **商业模式与竞争优势**：公司如何赚钱、增长依赖什么、竞争优势是否有证据。管理团队、供应链、客户和文化仅在影响判断时展开，不套用护城河术语代替事实。
3. **财务质量与排雷**：围绕盈利、成长、偿债、营运和现金创造中的重大变化分析。只展示支撑判断的指标，按公司类型选择合适口径；银行、保险、证券不强套一般工商业指标。无异常项目简述即可。
4. **估值**：主 Agent 根据业务、盈利阶段和可用证据选择合适方法，按需使用 `company-valuation` 或对应能力直接计算。区分观测数据与预测假设，说明区间、敏感因素及失效条件；条件不足时不强行给目标价。
5. **风险与跟踪**：哪些证据最可能推翻当前判断，后续关注什么。

历史估值只使用接口实际可访问的区间，不强制三年或 36 个月末逐次查询。优先获取可用区间的必要字段，再由主 Agent 程序抽样；注明覆盖期，数据不足时不宣称长期历史分位。同行比较仅在有同口径可比数据时进行。
