# 技术面分析

主 Agent 基于量价数据刻画趋势、波动和关键价格区间，输出 `final-output-analysis-technicals-{stock_code}.md`。采集、计算和交付遵守 SKILL.md。

## 数据与计算

- 将所需 OHLCV 采集交给数据 Sub-agent，通常以近 200 个交易日作为观察窗口，按研究目的调整，并为指标计算保留必要预热期。日期范围、字段数和条数上限先核对；不足时报告实际覆盖范围。
- 优先使用来源确认的前复权行情。接口未声明支持 `adjust` 时不传该参数；默认返回值不自动等于前复权或不复权。文件名和正文按已确认的实际口径命名与描述，未知则明确未知。
- 主 Agent 让工具从文件读取行情，核对排序、重复日期、缺失记录、单位及指标预热期；通过 `tech-indicators` 或对应本地计算能力批量计算选定指标。不将本地指标工具当作行情采集接口，不为计算创建 Sub-agent。
- 按问题选择趋势、动量、波动或量价指标，不要求 SMA、EMA、RSI、MACD、BOLL、OBV、KDJ、ATR 全部计算或全部输出历史序列。同口径结果可复用，派生指标与原始行情分开保存。
- 除权或复权口径不明且影响跨期比较时，不输出依赖该连续性的可靠收益或技术信号判断；缩小到可验证范围或说明无法判断。指标预热不足的值不当作正常信号。

## 分析与成稿

1. **量价状态**：说明观察窗口、最新数据日期、趋势和成交量变化。比较窗口按研究目的选择，涨跌幅由主 Agent 批量计算，不固定计算每个价格组合。
2. **关键指标**：展示能支持或反驳判断的指标、参数、数值和适用条件。避免把多个高度相关指标当成独立证据，也不把超买超卖直接解释为反转。
3. **关键价格区间与风险**：基于可核验的历史高低点、成交结构或波动方法识别区间，解释选择依据和失效条件；不能用当前价固定乘以黄金比例等常数直接制造支撑阻力，也不默认套用统一 5% 过滤阈值。缺少证据时不强行给数值。
4. **量化研究假设（适用时）**：有明确问题时提出可观测条件与待检验结果，说明信号公式、参数依据、样本、基准、观察期及失效条件；不输出交易执行指令。

若需要比较上下空间，可使用 `UpDistance = (Resistance - Price) / Price`、`DownDistance = (Price - Support) / Price` 及二者比值，前提是价位与价格口径一致且 `0 < Support < Price < Resistance`。不满足条件时标注不可计算，不解释为收益承诺。

量化假设的验证设计需考虑复权、成本、未来数据泄漏、训练与验证划分，以及样本覆盖、超额收益、回撤和参数稳健性。未实际回测时明确“待验证”，不能宣称策略有效；不为附带一个假设自动扩大为完整回测任务。
