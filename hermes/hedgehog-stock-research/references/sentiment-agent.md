# 情绪与消息面分析

主 Agent 提炼公司的市场叙事、多空分歧和潜在催化剂，输出 `final-output-analysis-sentiment-{stock_code}.md`。采集、计算和交付遵守 SKILL.md。

## 证据范围

先复用已有公告、估值与资金流材料，再将明确缺口交给数据 Sub-agent：

- 近期公司新闻、公告、研报：围绕本次研究问题检索，按重要性去重，保留标题、发布日期、来源标识和必要原文位置。研报观点是观点，不直接作为公司经营事实。
- 行业与宏观信息：只取能解释公司定价或经营预期的事项，不固定每类采集数量，不为章节配图扩大取数。
- 资金流、成交量和估值：说明实际日期、单位与覆盖范围，供主 Agent 比较或批量计算；与基本面、技术面共用数据只取一次。

时间范围以当前接口能力为准。公告起始日期的历史限制不能靠分段突破；查找最新完整财报时可按数据技能支持的方式不传起始日期，再核对候选报告期，但这不代表已完整覆盖三个月公告。无法覆盖目标窗口时明确缺口，不反复试错。历史 PE/PB 不固定要求三年，也不逐季度重复查询。

## 分析与成稿

1. **市场叙事与估值定位**：市场正在关注什么，叙事有哪些事实支撑？历史估值位置只基于实际样本，隐含增长等模型结果须披露假设。
2. **核心分歧**：选择会改变判断的多空分歧，分别提供最强证据。宏观、产业和公司事件按关联性纳入，不强行各写一章。
3. **资金与价格的配合**：描述可观测变化及可能解释，不把资金净流入直接等同于机构看多，不由股价变化反推已证实的动机或情绪。
4. **催化剂与跟踪**：哪些事件可能验证或证伪当前叙事，时间和落地条件是否已知？区分已披露安排与研究假设。

没有社交媒体或一致预期样本时，不能声称覆盖全市场情绪或市场共识。预期差是待验证判断，需要事实链和反方解释，不预言必然的价格反应。

需要图表时仅使用已核验数据。引用、尾注与 AI 提示统一按 SKILL.md 和系统规范输出。
