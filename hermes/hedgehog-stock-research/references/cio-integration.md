# CIO 综合研报

由主 Agent 综合基本面、情绪面和技术面的证据形成独立判断，输出 `final-output-research-{stock_code}-{YYYYMMDD}.md`。支持整合已有报告及从头完成完整研究；分工、计算、分段写入和终检统一遵守 SKILL.md。

## 输入与核查

使用本任务产出或用户提供的专项报告，确认公司、研究截止日、各报告覆盖期及来源。已有报告整合按实际材料范围完成，缺失维度如实说明；从头完整研究则由主 Agent 完成三维度分析后整合。

重点对齐最新价格与估值基准、报告期、单位、复权方式和预测假设。同一事实出现不同数值时回查来源，不能简单平均或挑选支持结论的数值。历史截止日之后发布的材料不得用于当时判断。

## 综合判断

- **核心矛盾**：哪些经营事实、估值假设和市场预期最可能改变公司价值判断？呈现最强的支持与反对证据。
- **市场定价**：价格反映了怎样的预期？区分市场叙事、主 Agent 推断与估值模型假设；无法验证是否充分定价时保留不确定性。
- **维度冲突**：基本面、情绪和技术信号不一致时，说明时间尺度、数据质量或假设差异，给出判断依据，不机械投票。
- **跟踪与验证**：列出能验证或证伪判断的事件和数据。有研究价值时提出可回测假设，说明样本与方法局限，未回测标注“待验证”，不写成交易指令。

## 分段成稿

按 SKILL.md 的交付主结构逐章保存，必要时拆为小节。可以先写摘要，也可以正文完成后补入；已写章节以局部编辑修订，避免一次输出整篇超过上限。

整合时去重、重组并保留关键证据、反方解释、适用条件和引用。根据需要读取多份报告的相关部分，发现矛盾允许回读，不依赖字数受限的中间结论。不要求全文原样拼接；用户明确要求保留完整专项报告时，将其作为独立附件交付。

汇总实际使用的引用及图表数据，避免重复尾注和失效编号；核对成稿中的数值、条件与来源一致，解释尚未解决的冲突和覆盖缺口。
